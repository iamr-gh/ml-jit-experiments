# Zig ML Compiler Experiments

## Specific Rules
Do not generate extraneous comments in the codebase. 
Strive to explain code with descriptive names and simple logic.
Only use comments when meaning would not be clear to a human who was an expert.
Strive to write simple efficient code with minimal duplication.
Write unit tests per file, and run ``zig test`` after each generation to verify that functionality is maintained.
